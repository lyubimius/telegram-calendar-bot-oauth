Privacy Policy

Effective date: 30 October 2026

Overview

Telegram Calendar Bot is a personal-use application. It connects approved Telegram users with their Google Calendar and Google Tasks data.

Data the app accesses

  • Google Calendar lists, event titles, dates, times, descriptions, and related event metadata.
  • Google Tasks lists, task titles, due dates, and completion status.
  • Telegram identifiers and messages needed to process commands and deliver notifications.

How data is used

Google user data is used only to display calendar events and tasks, create or modify items requested by the user, generate daily summaries, and notify the user about relevant changes. The app does not sell user data, use it for advertising, or share it with data brokers.

Storage and security

OAuth credentials and operational state are stored locally on the owner's secured device. Credentials, access tokens, calendar contents, and task contents are not committed to the public source repository. Access is limited to explicitly approved users.

Data sharing

Data is transmitted only to Google APIs and Telegram as required to provide the requested functionality. The app does not transfer Google user data to unrelated third parties.

Retention and deletion

Operational state is retained only while needed to run the bot. An approved user can revoke access at any time from their Google Account permissions. The owner can delete locally stored credentials and state to remove the app's retained access and data.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy may be sent to the support email displayed on the Google OAuth consent screen.
